# Zamzam Fragrance Studio

Create a premium, modern, responsive FRONT-END ONLY website for a Canadian perfume brand called Zamzam Fragrances Canada.

1. PROJECT CONTEXT

Zamzam Fragrances Canada is a perfume brand currently selling fragrances through Instagram and physical event stalls in Canada.

The goal of this first phase is ONLY to create a high-quality static front-end website / visual prototype.

IMPORTANT:

Do NOT build a backend.

Do NOT create a database.

Do NOT implement real authentication.

Do NOT implement real payments.

Do NOT implement real order processing.

Do NOT implement real shipping integration.

Do NOT connect to any external e-commerce backend.

Product data can be static/mock data for this prototype.

Any cart interaction should be front-end only using local state/JavaScript.

The website will be connected to a backend later if the client approves the design.

The main objective is to impress the client visually and demonstrate what the future Zamzam online store could look like.

2. BRAND INFORMATION

Brand name:
Zamzam Fragrances Canada

Instagram:
https://www.instagram.com/zamzamfragrancescanada/

Business location:
Vancouver, British Columbia, Canada

The brand sells inspired versions of luxury/designer fragrances.

The expected catalog is approximately:

25–30 fragrance products

Each fragrance can have:

30ml

50ml

100ml

Current approximate price range:

30ml: around $25–$30 CAD

100ml: around $50–$85 CAD

50ml pricing can be represented appropriately in the prototype.

Examples of fragrance inspirations mentioned by the client include Dior Sauvage and Coco Chanel.

IMPORTANT:
Do not make false claims that Zamzam is affiliated with or officially represents Dior, Chanel, or other luxury brands.

3. DESIGN DIRECTION

The website should feel:

Premium

Elegant

Luxurious

Modern

Sophisticated

Minimal

High-end perfume boutique

Professional enough for a Canadian e-commerce brand

The client specifically requested a red and blue color palette.

Use these colors intelligently rather than making the entire website bright red and blue.

Suggested visual direction:

Deep navy / dark blue as the main dark color

Burgundy / elegant red as an accent

White / ivory for clean sections

Subtle gold or neutral metallic details only if necessary

Strong contrast

Large typography

Generous whitespace

High-quality perfume imagery

Subtle gradients

Glassmorphism only where appropriate

Elegant shadows

Do NOT make the design look cheap, generic, overly colorful, or like a template.

Zamzam logo/brand name prominently displayed

Short brand statement

The hero should immediately communicate luxury and fragrance.

Cartoon-style imagery

Overly colorful backgrounds

If actual Zamzam product photos are not available, use appropriate temporary imagery and structure the code so the images can easily be replaced later.

21. LOGO

Use the existing Zamzam logo provided by the client if available.

24. IMPORTANT CLIENT PRESENTATION GOAL

This website will be presented to the client as a visual prototype.

Therefore prioritize:

Visual quality

Premium branding

User experience

Product presentation

Smooth interactions

Professional animations

Clean architecture

Do NOT spend effort on backend functionality at this stage.

The client should look at the website and immediately understand what the future Zamzam online fragrance store could become.

FINAL DESIGN FEEL

Luxury perfume boutique + modern Canadian e-commerce brand + cinematic fragrance experience.

The result should look polished, premium, sophisticated, and production-ready from a visual perspective, while remaining 100% front-end only.
